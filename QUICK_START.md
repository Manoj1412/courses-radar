# Quick Start Guide - AI Features

## 🚀 Getting Started in 60 Seconds

### Prerequisites
- Node.js 18+ installed
- pnpm package manager (`npm install -g pnpm`)
- Valid YouTube API key (already configured)
- Valid Gemini API key (already configured)

### Step 1: Install Dependencies
```bash
cd /vercel/share/v0-project
pnpm install
```

### Step 2: Start Development Server
```bash
pnpm run dev
```

The application will start at `http://localhost:5173`

### Step 3: Test the Features

#### Test AI Chatbot:
1. Search for a course topic (e.g., "Python")
2. Click on any video from results
3. Click the **Message Square icon** (💬) in the video player header
4. Click "Summary" tab → Click "Load Summary"
5. Click "Quiz" tab → Click "Start Quiz" → Answer questions

#### Test Emotion Feedback:
1. Open a video (allow camera access when prompted)
2. Make different facial expressions while video plays
3. Check ChatPanel to see emotion data:
   - Emotion detection status
   - Confidence levels
   - Detected emotions with percentages

#### Test Quiz History:
1. Complete a quiz (as above)
2. Click "History" tab in ChatPanel
3. See all previous quiz attempts with scores
4. Click any attempt to see full feedback

## 🐛 Troubleshooting

### Issue: "Message not appearing after quiz"
**Solution**: Check browser console (F12 → Console tab) for errors. Refresh page if needed.

### Issue: "Can't access camera"
**Solution**: 
- Grant camera permissions when prompted
- Check browser permissions settings
- Try in incognito mode

### Issue: "Quiz not generating"
**Solution**:
- Verify GEMINI_API_KEY in .env
- Check internet connection
- Look for API errors in console
- Ensure video title/description are not empty

### Issue: "Quiz history not saving"
**Solution**:
- Clear browser cache and cookies
- Check if IndexedDB is enabled in browser
- Try with more storage space available
- Check browser console for quota errors

## 📊 API Limits & Quotas

### Gemini API:
- Free tier includes generous quotas
- ~1500 API calls per day typically
- Rate limited to 15 requests per minute

### IndexedDB Storage:
- Typically 50-100MB per origin
- Auto-cleans old entries per video
- Fallback to localStorage if needed
